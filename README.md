## Current Projects

# ⚔️ Tower Of Eternal Eclipse

A turn-based roguelite dungeon crawler (Alpha Released)

Features include:

- Multiple playable classes with unique abilities
- Turn-based combat
- Boss battles
- Character progression
- Dungeon exploration
- Story & lore
- Save & Load system using JSON
- Automated battle simulations for balancing
- Ongoing development with planned future graphical version

# 🌙 Luna

An AI/ML-powered learning companion for Tower Of Eternal Eclipse.

Currently focused on:

- Analysing battle simulation data
- Predicting game balance
- Visualising statistics
- Helping improve gameplay using machine learning

This project is also my practical journey into AI, Machine Learning and Data Science.

# 🌌 2D Orbital Simulator

A physics-based simulation built with Python + Pygame (v1.0.0 Released)

Features include:

- True n-body gravity simulation
- Leapfrog integration for stable orbits
- Camera pan & zoom
- Orbit trails
- Adjustable simulation speed
- Pause / Resume controls
- Interactive body spawning
- Real-time HUD
- Notification system

---

# ⏰ ClockBound

A 2D platformer created for GMTK Game Jam 2026 using Python and Pygame.

Built collaboratively with my team under a strict game jam deadline, focusing on gameplay systems, level rendering and player mechanics and teensy tiny bits of image editing.
