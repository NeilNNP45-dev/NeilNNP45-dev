## 🌙 Luna

### ML Companion and Balance Tester For Tower Of Eternal Eclipse

Luna started as an experiment:

*"Can a machine learn from my game?"*

Now it is becoming a small AI companion that analyses battles, finds patterns, and helps improve game balance.

Currently exploring:

- 🤖 Machine learning models
- 📊 Battle data analysis
- 📈 Data visualisation
- ⚖️ Game balancing experiments

Built with:

`Python` `Pandas` `Matplotlib` `Scikit-learn`
